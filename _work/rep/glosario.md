# Glosario de traducción — *Picatrix, Liber Atratus* (trad. Greer & Warnock)

> Grimorio de **magia astrológica** (*Ghāyat al-Ḥakīm*, s. X; versión latina hecha para
> Alfonso X, 1256). Traducción inglesa de John Michael Greer & Christopher Warnock.
> Consistencia obligatoria en los cuatro Libros. El traductor NO edita este glosario:
> reporta los términos nuevos que encuentre.

## Título y estructura
- ***Picatrix*** → ***Picatrix*** (invariable, en cursiva cuando designa la obra).
- ***Ghāyat al-Ḥakīm*** → se conserva en cursiva, con sus diacríticos intactos.
- **Book One/Two/Three/Four** → **Libro Uno/Dos/Tres/Cuatro**; **Chapter N** → **Capítulo N**
  (se conserva el ordinal en palabra: *Chapter Seven* → *Capítulo Siete*).
- **Prologue** → **Prólogo**; **Glossary** → **Glosario**; **Bibliography** → **Bibliografía**.

## Vocabulario nuclear de la magia astral
- **image** (talismán grabado) → ***imagen***; **magical image** → *imagen mágica*. NO «estatua».
- **talisman** → *talismán*; **seal** → *sello*; **figure** → *figura*.
- **suffumigation** → *sufumigación*; **to suffumigate** → *sufumigar*; **incense** → *incienso*.
- **confection** → *confección* (preparado); **elixir** → *elixir*; **coction** → *cocción*.
- **working(s)** → *operación(es)*; **experiment** → *experimento*; **work** (sust.) → *obra/trabajo*.
- **virtue** → ***virtud*** (poder inherente; NO «cualidad moral»); **power** → *poder*;
  **influence** → *influencia*; **property** → *propiedad*.
- **spirit** → *espíritu*; **rational spirit** → *espíritu racional*; **spirit of the planet**
  → *espíritu del planeta*. **soul** → *alma*.
- **nigromancy / nigromancia** → ***nigromancia*** (arte mágica en sentido medieval, no
  «necromancia»: no es evocación de muertos). **magician** → *mago*; **sage(s)** → *sabio(s)*;
  **the wise** → *los sabios*; **philosopher** → *filósofo*.
- **prayer** → *oración*; **petition** → *petición*; **invocation** → *invocación*;
  **sacrifice** → *sacrificio*.
- **lesser world / greater world** → *mundo menor / mundo mayor* (microcosmos/macrocosmos).

## Astrología (fijado como en el resto de la biblioteca)
- Planetas: **Saturn, Jupiter, Mars, Sun, Venus, Mercury, Moon** → *Saturno, Júpiter, Marte,
  Sol, Venus, Mercurio, Luna*. Glifos ☉☽♄♃♂♀☿ intactos si los hay.
- Signos: *Aries, Tauro, Géminis, Cáncer, Leo, Virgo, Libra, Escorpio, Sagitario, Capricornio,
  Acuario, Piscis*.
- **ascendant** → *ascendente*; **midheaven** → *medio cielo*; **house** → *casa*;
  **angle / succeedent / cadent** → *ángulo / sucedente / cadente*.
- **domicile, exaltation, detriment, fall, term, triplicity, face, decan** → *domicilio,
  exaltación, detrimento, caída, término, triplicidad, faz, decano*.
- **conjunction, opposition, trine, square, sextile** → *conjunción, oposición, trígono,
  cuadratura, sextil*. **aspect** → *aspecto*; **application** → *aplicación*.
- **retrograde** → *retrógrado*; **combust** → *combusto*; **under the rays** → *bajo los rayos*.
- **mansion(s) of the Moon** → *mansión(es) de la Luna*.
- **Head / Tail of the Dragon** → *Cabeza / Cola del Dragón*.
- **lord of X** → *señor de X*; **significator** → *significador*; **nativity** → *natividad*.
- **hour of Venus** → *hora de Venus* (horas planetarias). **degree** → *grado*.
- **fixed stars** → *estrellas fijas*; **eighth sphere** → *octava esfera*; **sphere** → *esfera*.
- **fortunate / unfortunate, benefic / malefic** → *afortunado / desafortunado, benéfico / maléfico*.

## Materia médica, minerales y pueblos
- Nombres de plantas, piedras y drogas: traducir al término español corriente cuando sea
  seguro; **si hay duda, conservar el original en cursiva** y no inventar equivalencias.
- **Nabateans** → *nabateos*; **Chaldeans** → *caldeos*; **Hindus** → *hindúes*;
  **Harranians / Sabians** → *harranianos / sabeos*; **Copts** → *coptos*.
- Nombres propios árabes y sus transliteraciones (**Ibn Waḥshiyya**, **al-Majrīṭī**…) se
  conservan **con sus diacríticos exactos**. Nunca «corregirlos» de memoria.

## Registro y convenciones de entrega (firmes del usuario)
- Registro **académico y sobrio**, sin arcaísmos postizos; el texto es medieval pero la
  traducción inglesa es moderna: no se arcaíza de más. `&c.` → *etc.*
- Notas `[^N]` **ancladas donde están**, misma numeración, sin encabezado «Notas» vacío.
- **Sin índice analítico** salvo petición. Prosa en párrafos; **nunca líneas hiperextensas**.
- Cifras, grados, glifos y nombres mágicos (*voces magicae*: nombres de espíritus y palabras
  de poder) **intactos**: NO se traducen ni se «normalizan».
- Bibliografía y glosario: los **títulos de obras** no se traducen; en el glosario se traduce
  la definición y se conserva el lema original en cursiva.
- ⚠️ El texto describe operaciones con **sustancias tóxicas** (venenos, drogas): se traduce
  como documento histórico, sin añadir ni suprimir nada.
